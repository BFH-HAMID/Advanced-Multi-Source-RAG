# README artwork

Every image in the top-level `README.md` lives here and is generated from source, so the docs can be
rebuilt instead of hand-edited.

| File | What it is | Generated by |
| --- | --- | --- |
| `banner.svg` | animated hero banner (gradient title, stack pills, three-index → answer motif) | `scripts/generate_readme_assets.py` |
| `pipeline.svg` | annotated 1→10 pipeline diagram with animated packet flow | `scripts/generate_readme_assets.py` |
| `demo.svg` | animated CLI + chat demo (SMIL timeline) | `scripts/generate_readme_assets.py` |
| `demo.gif` | the same demo as a looping GIF, for viewers that ignore SVG animation | `scripts/render_demo_gif.py` |
| `eval-report.png` | evaluation chart built from the latest RAGAS report | `scripts/generate_readme_assets.py` |
| `social-card.svg` | 1280×640 repo/social preview card (upload it manually in GitHub repo settings) | `scripts/generate_readme_assets.py` |
| `fonts/HindSiliguri-*.otf` | Bengali face, embedded as a data URI inside `demo.svg` | SIL OFL 1.1, see `fonts/OFL-HindSiliguri.txt` |

## Regenerate

```bash
pip install -r requirements-dev.txt          # matplotlib + pillow + resvg-py
python scripts/generate_readme_assets.py     # SVGs + eval chart (reads data/evaluation/*.json)
python scripts/render_demo_gif.py            # assets/demo.svg → assets/demo.gif
# or simply:
make assets
```

`generate_readme_assets.py --no-charts` skips the matplotlib step. The chart uses the evaluation
report with the most questions, so run `python scripts/run_eval.py --mode heuristic` first if
`data/evaluation/` is empty.

## Notes

* The SVGs animate with SMIL (`<animate>`, `<animateMotion>`) and CSS keyframes only — GitHub strips
  scripts from README images, so no JavaScript is used.
* `demo.svg` carries the Bengali font as a base64 `@font-face` because GitHub's image proxy will not
  fetch relative font files; that is why it is ~128 KB while the other SVGs are ~7–14 KB.
* `demo.gif` is rendered by sampling the SVG timeline frame-by-frame with `resvg-py`; keep
  `DEMO_LINES` in the generator as the single source of truth for both formats.
